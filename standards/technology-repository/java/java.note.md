# Overview

This document contains notes, observations, and decisions related to the use of Java technology within the organization.

# Notes

## 2026-01-22 - Initial Technology Registration

- Java registered as a **Standard** technology with **Global** scope
- Primary purpose: General-purpose application development
- Approved versions: Java 21 LTS and Java 25 LTS
- License model: OpenJDK (GPL v2 with Classpath Exception)
- Strategic direction: Continue as primary development technology
- Main category: Development Tools

### Key Decisions
- Java 21 and Java 25 LTS versions approved for use across all projects
- OpenJDK selected as the standard distribution for cost efficiency and open-source benefits
- Technology classified under "Development Tools" category
- Global scope applies to all organizational units and projects

### Considerations
- Monitor Java release cycle (every 6 months) and evaluate new LTS versions as they become available
- Consider migration path for projects still using older Java versions (8, 11, 17)
- Ensure development teams have access to proper training for modern Java features (virtual threads, records, pattern matching)
- Evaluate need for commercial support subscriptions for critical production systems
