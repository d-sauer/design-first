# Tech Registry Portal

A technology repository web portal for managing organizational technology governance and collaboration. The portal enables broader organization to understand the direction of used technologies, manage approved (greenbook) and prohibited (blackbook) technologies, facilitate collaboration on technology proposals, and empower teams to learn about the technology landscape.
