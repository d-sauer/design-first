# Domain Creation Skill

Create or update domain based on a given description.
Domain is specific area of business activity, knowledge, or expertise that an organization operates in and that software systems are designed to support.
It encompasses the real-world processes, rules, terminology, and problems that define what a business does.

## When to Use

Creating a new domain
When we discover new business domain
Documenting existing domain

## Workflow

1. Provide a brief description what is this domain about?

2. Identify what are the main business capabilities of this doamin?

3. AI suggest domain name based on given description and capabilities

4. Provide a short name for this doamin or choose from provided list?
  

## Outcome

- create folder in `./domains` folder with domain name

- create `README.md` file containing information about the domain
Example
```
# Domain name

brief description of the domain

## Capabilities
- list of capabilities of this domain

```
