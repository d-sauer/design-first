# System Landscape

Purpose of System Landscape is to capture general view of environment and interaction. Goal is to capture landscape snapshot and what are the main connections between systems, and what is their interaction about.

## Workflow

### Step 1: Identify systems and purpose

On the high level, how you enterprise system looks like:

- Confirm relevant work item `/work`
- How would you name your landscape?
- List the main systems of your enterprise landscape?
- How those systems interact and what is the interaction about?

### Step 2: Output

- Create minimal document about the system landscape, following template `./template/system-landscape.md`
- create final document in `work/{work-item}/architecture/system-landscape`
