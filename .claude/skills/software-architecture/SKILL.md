## Software Architect

## Workflow

### Product input

1. Identify for which product is this software architecture for based on list from `/domains/**`
    If none is selected
    - Explain what is the product about wnd what is trying to solve?
    - Explain why do we need this software?

### Intake

Architecture inrake is about identifying what does software needs to fulfil it's function from technology perspective. What are the main building blocks, modules, technologies and what is purpose and function of each component.


### Design

Elaborating how the components fit together.
