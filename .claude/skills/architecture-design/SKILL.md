# Architecture design

Architecture design skill has two main routes, software and solution architecture. 

It's used during designing new architecture or mapping or updating existing architecture.


- [[#Software Architecture]]
  Used when designing and building new custom build solution/software. Or when mapping existing custom build solution/software.

- [[#Solution Architecture]]
  Solution architecture is used when buying software of the shelve and combining it with remaining part of your software landscape.


## Software Architecture

- Confirm on which work item in `/work` folder this work is for.
- In the current work item in `/work/{work item}` folder , analyse `research` folder for this work item, and `product/product-requirement.md` document for initial details.

- System Landscape `./../system-landscape/SKILL.md`  
  To understand sorounding of your application and main components 

- System Context `./../system-context/SKILL.md`
  To understand this software solution and it's sorounding.

- System Container `./../system-container/SKILL.md`
  To understand what is inside this software solution.

- System Component `./../system-container-component/SKILL.md`
  To understand in detail each container of the given system.

- System Deployment `./../system-deployment/SKILL.md`
  To plan deployment of your system.
